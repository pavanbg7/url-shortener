# URL Shortener

A web application that converts long URLs into short, shareable links.

## Live Demo
[Try it here](https://your-app.onrender.com) 

## Features
- Shorten any long URL instantly
- Redirect to original URL via short code
- Stores all links in a SQLite database
- Clean, responsive UI

## Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite
- **Deployment:** Render

## Run Locally
```bash
git clone https://github.com/pavanbg7/url-shortener.git
cd url-shortener
pip install -r requirements.txt
python app.py
```
Then open http://localhost:5000 in your browser.
